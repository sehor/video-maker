# AI 视频镜头工厂开发文档 v2.0

> 日期：2026-08-17｜形式：分阶段、按需加载  
> 产品：只做短剧／漫剧视频镜头；只交付 720p／1080p；不做图片、2K／4K／8K和 AI 超分。

## 使用规则

开发时只加载：

```text
00_开发总纲.md + 当前阶段文档
```

修改数据库、状态机、账本或 Provider／Worker 协议时，再加载 `90_核心数据模型与接口契约.md`；新增依赖、模型、节点或 Worker 镜像时，再加载 `91_外部依赖与许可证.md`。不要一次加载全部文件。

## 审查后的关键调整

1. **New-API 移出首版主链路。** 第一条自部署路线不需要网关；商业 API 出现后再按实际协议选择专用 Adapter 或 New-API。用户秒数始终以自有账本为准。
2. **`worker-comfyui` 只视为 RunPod／ComfyUI 基础 Worker。** 阶段三先 POC 验证 MP4 产物收集、上传、错误和冷启动，再决定薄适配范围。
3. **Hatchet 不保存业务真相。** PostgreSQL 保存 Job、Attempt 和账本；使用 Transactional Outbox 启动工作流，所有数据库及外部副作用放在幂等任务中。
4. **MVP 表大幅缩减。** 模型、节点、工作流和许可证先用不可变 manifest 管理，不提前建设模型市场式后台。
5. **Vast、SkyPilot、真实支付、完整监控和 1080p 后置。** 先把一条 720p 路线跑稳定，再依据数据扩展。
6. **FastAPI OpenAPI 是唯一接口契约。** 前端 Client 自动生成，不维护两套 DTO。
