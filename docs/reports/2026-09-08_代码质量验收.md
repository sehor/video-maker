# 代码质量改进验收

日期：2026-09-08。范围：计划二 CQ-01 至 CQ-07；本地实现与验收完成，远程 CI 未运行。

## 结构与行为对比

| CQ-01 基线 | 当前实现与证据 |
|---|---|
| public_api 混合路由、接单事务和依赖组装 | 4 组 HTTP 路由委托 application 服务，bootstrap 组装依赖；HTTP 不提交业务事务 |
| GenerationExecutionService 多继承与兄弟类隐式方法 | 7 个独立类通过构造参数组合；AST 检查所有 self 依赖来源 |
| Mock/远端完成逻辑交织 | Mock 和远端 Receiver 分离，Completion 统一 Output、终态与结算提交 |
| 前端手写请求泛型和宽泛路径 | 由 OpenAPI 路径、方法、参数、请求体推导响应；开发契约单独生成 |
| async 直接执行同步数据库与文件操作 | 每个事件循环最多 4 个受控同步任务，事务内自行创建/关闭 Session；取消等待资源释放 |
| BinaryIO 累积字节块再 join | 1MiB 分块磁盘暂存；Local 独占写、远端 seekable 流；下载结束或断开关闭文件 |
| 边界主要依靠文档约定 | 5 项默认架构检查，扩展 Ruff 与双契约生成检查，保留媒体进程启动拦截 |

接单幂等记录、冻结、Attempt、Outbox 仍在同一事务；Output、终态、SETTLE/RELEASE
仍在同一完成事务。账本领域函数不自行提交。23 个项目/账本/生成用例与基线
`8cd6f30` 的业务函数 AST 对比相同（仅调整模块引用和 HTTP 响应映射）。
其余有意改动通过对应回归验证，未降低金额、幂等、权限、重试、恢复或对象所有权断言。

## 性能测量

Windows 10 19045、Python 3.13.7，运行期间有其他开发进程，未固定系统负载。
注入 2 秒同步阻塞、20ms 心跳：原调用最大间隔 2009.97ms；改造后的执行入口慢 Session
113.57ms、受控文件写入 361.57ms，均低于单测 500ms 目标。

惰性流输入从 64MiB 增至 512MiB，Local 额外峰值从 2.070 增至 2.074MiB；
Remote + 磁盘 fake 均约 2.070MiB，低于 64MiB 单流预算。基准脚本
`scripts/benchmark_storage.py` 使用独立子进程和 Windows 进程峰值工作集，分块回读核对内容。
详细表见 [CQ-06](../plans/issues/CQ-06.md)。磁盘暂存增加一次复制；本结果不是云 SDK、
网络或多并发负载测量，也不代替真实路线 SLA。
