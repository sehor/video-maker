## 本地验收证据

- 根因：独占创建 `xb` 失败后无条件 `unlink`，会删除之前已提交或并发成功的对象。
- 修复：仅成功打开本次新建文件后才取得清理资格；创建失败保留原对象，写入或关闭失败清理本次新文件。
- 修复前，顺序重复写入与真实 LocalObjectStorage 并发测试均复现对象丢失。
- 修复后，Storage 共享契约与故障回归：39 passed（0.35s）。
- 命令：`uv --cache-dir .tmp-uv-cache run --project apps/api --no-sync python scripts/test.py python apps/api/tests/test_storage_contract.py`。
- Ruff check 和 format --check 通过（范围为上述两个 Python 文件）。
