# CQ-05：有界同步 IO 执行

状态：2026-09-08 实现及定向验证完成；最终 E2E 与 CQ-06 集成在 CQ-07 统一复核。

`blocking_io.py` 每个事件循环最多 4 个在途同步任务，先获取名额再提交线程。
取消等待线程自行退出并完成句柄/临时对象清理，期间不提前释放名额；排队取消不启动工作。
线程不可被安全强杀，所以 shutdown/timeout 可能等待底层 IO 完成；数据库原有超时仍生效。

Execution 的上下文、握手、预算、事件与完成事务，Outbox、取消租约、产物/项目清理、
reconciler、启动就绪与 Local executor 构造改为受控执行。Provider async 网络接口保持异步。
上传传递普通 ID 和文件流，不跨线程传递 ORM session；工作线程自行创建并关闭 session。
文件传输前授权、传输后重新锁定并核对项目，业务事务不跨越文件传输；删除竞争清理本次对象。

Windows 10 19045、Python 3.13.7，20ms 心跳、注入 2 秒阻塞；运行时有 Codex 和其他
开发进程，未人为固定 CPU 负载。这是确定性单测，不能替代真实路线 SLA 压测。
